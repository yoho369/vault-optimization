# Recursive Yield Optimization & Tail-Risk Asset Allocation for LSD Vaults

A quantitative framework analyzing recursive leveraged staking strategies (e.g., looping ETH/stETH across DeFi lending venues like Aave and Morpho). 

This [short report](./vault_optimization.pdf) discusses the concepts of formulating leveraged liquid staking structures, evaluating capital allocation using a Mean-CVaR optimization model to handle tail risks during depegging events, and introduces a 7-factor quantitative risk-scoring matrix across market volatility, trading frictions, and smart contract protocol dependencies.
